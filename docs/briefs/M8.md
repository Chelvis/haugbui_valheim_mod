## 3. Product rules (PRD §15, §5, decisions log §23)

- **HB-140** Combat is available only while the Longsword is bound; toggle default **OFF**.
- **HB-026 / HB-T-074** The first enable shows the combat warning as a **confirmation** (YesNoPopup or equivalent
  vanilla popup — verify the class in the decompile). Confirm → `combat_ack` stored and combat ON. Cancel → combat stays
  OFF and no ack. Once acknowledged, later enables need no confirmation. The bind-time warning stays.
- **HB-141 / HB-T-071** Valid targets inside the operational radius: alive, not players, not tamed, not Haugbuis,
  driven by monster AI (`MonsterAI`, not `AnimalsVeg`/`Players` faction), in loaded zones. **Bosses are valid targets**
  (decision 2026-10-16: at the player's own risk, no exclusion, no config). Scan about every 1 s through the registry
  (`Character.GetAllCharacters()`), never per-frame world scans (HB-200).
- **HB-142 / HB-T-072** On detection: suspend the current task **after the current atomic step**, alert sound if a
  cheap vanilla one fits (optional, capped), fly to the target, attack with the wraith-based melee (Humanoid default
  weapon, cloned/tuned `wraith_melee`), and when no hostile remains go back to work by **re-planning**.
- **Level scaling (decision 2026-10-16)**: new progression row **combat multiplier**, configurable like the other
  per-level CSV rows (`Progression` section), default `1.0, 1.2, 1.4, 1.6, 1.8, 2.0` for levels 1–6. It **multiplies
  the damage of its hits** and **divides the damage it takes** (level 6 takes half damage). Level-based only: the
  Altar grants no extra resistance (HB-053). The defence formula is marked **"to confirm"** in PRD §23 — implement it
  as written; tell Kelvin how it feels.
- **HB-143** Collateral damage to player pieces near the enemy is allowed by design.
- **HB-144 / HB-T-073 (decision 2026-10-16)** Combat OFF: never initiates attacks. Flight is triggered **only by
  taking damage** (being targeted does not count — monsters target it all the time). It flies to its tomb and **waits
  next to it without entering** (entering would end the shift, and the next emergence would be charged again,
  HB-167); when no attacker remains it resumes work (re-plan). Dawn/Rest/death rules still apply while it waits.
- **HB-145** Several Haugbuis may attack the same enemy without state conflicts (no reservation needed for targets).
- **HB-013** Losing the Longsword (destroyed/unbound) or turning the toggle off ends combat **at once**.
- **HB-046** Combat and flight are **paused during sleep fast mode** (`EnvMan.IsTimeSkipping()`).
- **Interrupt priority** (ARCHITECTURE §5): Combat > Returning(dawn) > tasks; an interrupt never splits an atomic
  step. Decide and document how combat interacts with the dawn return lead (safest: no new fight once the return lead
  started; finish the return) — if you choose, record it in PRD §23 as "to confirm".
- **HB-130/131** It can be damaged and killed only while outside the tomb; death moves carried items to tomb storage
  / overflow (existing code), cooldown as today.
- **Item safety (non-negotiable, AGENTS.md, HB-045/061)**: combat and flight never create, delete or duplicate items;
  carried items stay carried during combat and flight; transfers stay destination-first; with `StrictItemData` ON
  nothing becomes cheated or clean.
- No recipe crafting anywhere (HB-122) — irrelevant here, but do not add any.

Any choice the PRD does not answer: pick the safest option, add a row to PRD §23 marked **"to confirm"**, and tell
Kelvin.
