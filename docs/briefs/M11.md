## 3. Product rules

### HB-T-117 — panels (confirmed 2026-10-28)

Kelvin's mocks are the target. Both editors share one typeahead.

- The search field is **above** the list. Typing filters the suggestions in that same field. There is no second
  dropdown and no Add button.
- Clicking a suggestion adds the item and hides the suggestions. The typed text stays. Suggestions show again only
  while the field is focused.
- A list taller than the panel scrolls.
- **Filter.** The list is the accept-only set, one item per row, name on the left, an X on the right that removes
  that row. No Remove button. Clear all empties the list. The rules underneath do not change: an empty list keeps
  HB-062; a non-empty list accepts only those prefabs.
- **Delivery.** An empty list says there is nothing to deliver (`$haugbui_*` in both languages). A new row shows how
  many of that item are already in the chest, and an empty field for the requested amount. Clear all is available
  only when the list has a row. Save stays disabled until every requested field has an amount. Saving still writes
  the same ledger as today (HB-082).
- **Close.** Every Haugbui panel (filter, delivery, tomb, production) gets an X in the top-right corner instead of a
  Close button. Esc and the gamepad back button still close them (HB-163). Closing never leaves movement blocked.
- **Vanilla chest.** Keep Shift+E. Add **Edit filters** on the vanilla chest window, and **Edit requests** on the
  delivery chest window. Each opens the same panel as Shift+E.
